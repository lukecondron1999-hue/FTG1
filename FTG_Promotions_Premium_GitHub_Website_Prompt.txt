GITHUB WEBSITE BUILD PROMPT — FTG PROMOTIONS
================================================

PROJECT
-------
Build a complete, production-ready, premium website for FTG Promotions (boxing promotion).

This is NOT a basic template, school project, or simple landing page. Treat FTG Promotions as a serious, high-end boxing promotion company that needs a website capable of handling major fight-night traffic, ticket sales, fighter promotion, media, press conferences, interviews and future events.

The finished website must look and feel like a premium VIP boxing brand and should be visually impressive enough to compete with — and outshine — major boxing promotion websites.

IMPORTANT:
- Build the actual working website, not just a mock-up.
- It must be responsive on desktop, tablet and mobile.
- It must be fast, accessible and SEO-friendly.
- Structure the project so it can be deployed immediately.
- Do not leave major features as fake buttons or unfinished placeholders.
- Where an external service/API/account is required, create the complete integration structure and clearly isolate the environment variables/configuration needed.
- Never hard-code secret API keys, payment keys or database credentials.
- Use environment variables for all secrets.
- Use a scalable architecture suitable for high traffic.

6. FIGHTER REFERRAL / DISCOUNT CODE SYSTEM
================================================

THIS IS A CORE FEATURE.

Every fighter must have a unique referral/discount code.

Example:

Fighter:
John Smith

Code:
JOHN10

Referral URL:
ftgpromotions.com/tickets?ref=JOHN10

If a customer purchases using that fighter's code/link:
- The code is attached to the order.
- The sale is attributed to that fighter.
- The system records the referral.
- The fighter earns 50% of the agreed commission/profit amount according to FTG's configured business rules.

IMPORTANT:
Do NOT simply calculate this in frontend JavaScript.

Referral attribution and commission calculations must be server-side.

Create a database model for:
- fighters
- referral codes
- referral clicks
- orders
- order items
- referral attribution
- commission records
- commission status

Commission statuses:
- Pending
- Approved
- Paid
- Cancelled/Refunded

Handle:
- duplicate clicks
- refreshes
- direct checkout
- expired codes
- refunded orders
- cancelled orders
- multiple products/tickets
- fraud/basic abuse protection

Create a secure admin dashboard where FTG can see:

FIGHTER REFERRAL DASHBOARD
- Fighter name
- Referral code
- Referral link
- Clicks
- Orders
- Tickets sold
- Revenue generated
- Commission generated
- Commission paid
- Pending commission
- Conversion rate

The system should make it extremely easy for FTG to give each fighter their unique link.
